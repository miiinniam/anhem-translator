## 六、检测方法说明

| 检测项 | 方法 |
|--------|------|
| WCAG 对比度 | 相对亮度公式计算 (WCAG 2.1)，浏览器 `getComputedStyle` 提取实际 RGB |
| 触摸目标 | `getBoundingClientRect()` 实测 DOM 元素像素尺寸 |
| 暗色模式覆盖 | 完整 CSS 代码审查 + 浏览器暗色模式模拟检测 |
| Flex 布局 | CSS computed style 检测 + 代码结构审查 |
| visualViewport | JS 事件绑定检测 + 行为分析 |
| 表单验证 | 交互测试 + 代码逻辑审查 |
