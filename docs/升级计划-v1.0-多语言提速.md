## 一、现状分析

### 1.1 慢的根因(按影响排序)

| # | 根因 | 说明 | 修复 |
|---|------|------|------|
| 1 | **思考模式默认开启** | DeepSeek 官方文档: `deepseek-v4-flash` / `deepseek-v4-pro` 默认 thinking=enabled(effort=high)。当前请求体未传 `thinking` 参数 → 每次翻译模型先输出整段 CoT 推理再给译文,首字延迟巨大 | 请求体加 `"thinking":{"type":"disabled"}` |
| 2 | **逐字打字机效果** | `TYPEWRITER_SPEED=28ms`,实际每字符 14ms → 300 字译文需额外 ~4 秒假延迟 | 提速到 ~6ms,超长译文(>600字)直接整段显示 |
| 3 | **系统提示词过长** | v0.98 安全墙+铁律+示例+自检 ≈ 1500+ tokens,每次请求都参与 prefill(虽有 prompt cache) | 中越对保留;其他语言对用精简通用提示词 |
| 4 | max_tokens 偏小 | 聊天模式 1024,长译文易截断 | 提到 2048(不影响首字速度) |

### 1.2 模型调研结论(官方文档 2026-08 抓取)

- **`deepseek-v4-flash`**(DeepSeek-V4-Flash-0731):输入 $0.14/1M(cache hit $0.0028)、输出 $0.28/1M、并发 2500 —— 当前用的就是**最快的模型**,没有更快的官方模型了
- **`deepseek-v4-pro`**:$0.435 / $0.87 / 500 并发 —— 更准更贵
- 结论:**"换模型"不如"关思考模式"**。提供模型切换 + 快速/深度思考切换,让用户自选

### 1.3 现有架构要点

- 单文件 `app.js`(698 行,IIFE 式全局函数)+ 单文件 `index.html`(PWA 灵动岛版)
- `detectDir()` 只分 中/越 两向;`dir` 字符串 "zh2vi"/"vi2zh" 贯穿:徽章、头像、通知、收藏、历史上下文
- `systemPrompt()` / `readPrompt()` 两套提示词,均为中越专用
- `setting2` localStorage 存 dialect/glossary;`profile` 存性别年龄;persona/语境/语气系统完备
- 计费 `PRICE = {hit:.5, miss:2, out:8}` 为旧价,需按模型更新

## 二、设计方案

### 2.1 速度优化(先做,收益最大)

1. **关闭思考模式**:两处 fetch(translate / translateRead)请求体增加 `thinking: { type: "disabled" }`
2. **模型选择器**(设置 → 翻译模型):
   - `Flash 快速`(默认,deepseek-v4-flash)/ `Pro 高质量`(deepseek-v4-pro)
   - 思考模式:`快速响应`(默认,thinking disabled)/ `深度思考`(thinking enabled,复杂长文更准)
3. **打字机提速**:`TYPEWRITER_SPEED 28→6`;译文 >600 字符直接整段渲染
4. **按模型计费**:`PRICE = { flash: {hit:0.02, miss:1, out:2}, pro: {hit:0.026, miss:3.1, out:6.2} }`(¥/1M tokens,按官方美元价×7.2 折算)

### 2.2 多语言支持

- **语言表** `LANGS`(14 种,可检测 + 可选母语):zh/vi/en/ja/ko/th/ru/ar/fr/de/es/pt/id/hi
- **`detectLang(text)` 脚本判定**(按优先级):
  - Hangul→ko · Kana→ja · 泰文→th · 西里尔→ru · 阿拉伯→ar · 天城文→hi
  - 汉字(Han)→zh(无 Kana 时)
  - 拉丁字母:出现 đ/ơ/ư/ă/â/ê 等越南语特征字符(占比>5%)→vi,否则→en
- **方向计算 `computeDirection(text)`**:
  - `src = detectLang(text)`, `tgt = 母语`
  - **若 src == 母语** → 输出对方语言(中→越 保持"写消息给女朋友"核心流程;母语=越时→中)
  - 其余情况一律 → 母语(如 输入英语 → 自动翻译成中文 ✓)
- **dir 字符串通用化**:`"en2zh"` 等;徽章显示 `英→中`;头像:src==母语(写消息)→meAvatar,否则 themAvatar
- **提示词分流**:
  - `zh↔vi` 对:保留 v0.98 完整安全墙/称谓/语气/方言/术语表(翻译质量不能降)
  - 其他语言对:精简通用提示词(只译不创/事实锁定/只输出译文),术语表仅当涉及越南语时附带
  - 称谓标注(`---原文称谓`)仅 vi→zh 输出,与现状一致

### 2.3 母语设置(设置 → 语言设置)

- `我的母语` 单选(默认中文):控制输出语言,保证"输出语言和设定一致"
- 说明文案:「输入其他语言自动翻译成母语;输入母语则翻译成越南语(给对方发消息)」

### 2.4 兼容性

- 复用 `setting2` 键(新增字段 `native`/`model`/`thinkMode`),老用户设置不丢
- `ctxKey()` 追加新字段 → 提示词缓存自动失效;旧收藏/旧卡片(带旧 ctxKey)仅不参与上下文,不影响展示
- 所有新 DOM 元素用 `if (!el) return` 防护,HTML 与 JS 可独立上线
