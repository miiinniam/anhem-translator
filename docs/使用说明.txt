【anhem 越南语翻译器 · 使用说明】                       by fayypp

■ 界面(2026 版全新聊天风)
  · 顶部合并成一条:品牌 · 聊天/阅读切换 · 💰花费 · ⚙设置
  · 下面一条「对话语境栏」:迷你的你 + 关系/性别/年龄 + 语气,
    右边是对方的迷你形象和称谓,一栏搞定
  · 译文以聊天气泡呈现,旁边带对方的小头像
  · 自动深色模式:白天亮色、晚上跟随系统自动切换为深色,不刺眼

■ 怎么打开
  电脑:双击 index.html 即可,无需安装任何软件。
  手机:界面已适配手机浏览器。想在手机上用,需要把这个文件
  放到手机能访问的地方(比如发到自己微信收藏后用浏览器打开,
  或以后部署成网页链接)。

■ 第一次打开:两步向导
  第一步 · 接入大模型
    翻译由 DeepSeek 大模型驱动,需要你自己的 API Key:
    1. 打开 platform.deepseek.com 注册(国内手机号即可)
    2. 充值少量金额(10 元能用很久)
    3. 左侧「API keys」→ 创建 → 复制(sk- 开头)
    4. 粘贴到向导输入框,点「连接并自动配置」
    系统会自动验证 Key、显示账户余额、自动完成全部模型配置。
    Key 只保存在你自己电脑/手机的浏览器里。

  第二步 · 创建你的迷你形象
    选性别、填年龄,生成你的动画小人。外观跟着年龄段变:
    25岁以下是刺猬头/双马尾,中年是花白头发或盘发,
    60岁以上是白发戴眼镜。性别年龄也决定越南语称谓。

■ 💬 聊天模式:先选「对方是谁」,再翻译
  语境栏里选当前对话的对象,两边的迷你形象会实时变化:
  · 情侣 / 暧昧对象     → anh–em(按你的性别定方向),腮红+爱心💗
  · 朋友 / 同事         → 按对方性别和年龄定
  · 客户 / 商务伙伴     → 礼貌称谓 + 敬语 ạ,西装领带🤝
  · 长辈(父母辈)      → cháu–cô/chú/bác,白发眼镜🍵
  · 陌生人 / 网友       → 中性的 tôi–bạn
  · 自定义              → 用中文描述关系,越具体越准
  · 🐶 我家狗子(彩蛋) → 铲屎官模式:自称 bố/mẹ,叫狗 cún,
                          右边是一只摇尾巴的狗

  语气选择(语境栏最右边的一排):默认 / 撒娇 / 生气 / 正式 /
  随意 / 幽默 —— 选一个,译文的口吻会跟着变(比如「撒娇」会
  多用叠词和 nhé/đi mà,「生气」会用短句省敬语)。

  输入中文 → 翻成称谓正确的地道越南语口语
  粘贴对方的越南语 → 翻成中文;对方称谓透露态度信号时
  (如情侣突然自称 tôi = 生气/疏远),显示黄色「称谓解读」

  跟不同的人聊天记得切换语境,每个语境的对话记忆互相独立。

■ 📖 阅读模式:长文翻译
  顶部切到「📖 阅读」,适合翻译文章、公告、合同、长消息:
  · 点「📋 一键粘贴并翻译」:自动读取你刚复制的内容并直接翻译
    (第一次浏览器会弹出剪贴板授权,点允许即可;
     如果浏览器不允许,就点输入框手动 Ctrl+V / 长按粘贴)
  · 译文完整保留原文段落结构,书面内容用规范书面语
  · 翻完点「复制译文」即可带走

■ 💰 花费统计(实时精确计费)
  每次翻译后,DeepSeek 会返回本次真实消耗的 token 数,系统按官方
  价格实时算出花费:
  · 每条译文下方显示「本次约 ¥0.0006 · 530 tokens」
  · 顶部💰药丸显示累计总花费,点它可打开设置看明细
  · 设置「📊 用量统计」里有累计花费、翻译次数、总 token,可清零
  计价标准:输入 ¥2 / 百万 tokens(重复内容缓存命中仅 ¥0.5),
  输出 ¥8 / 百万 tokens。正常一句聊天约几厘钱,¥10 能用很久。
  (此为本地估算,最终以 DeepSeek 官网账单为准)

■ 其他功能
  · 设置里可随时更换 API Key,点「检测」可查看余额
  · 北方(河内)/南方(胡志明) 用词风格切换
  · 术语表:人名、公司名的固定译法,聊天和阅读模式都会遵循
  · 对话记录保存在本机浏览器里,设置里可一键清空

■ 常见问题
  · 提示「余额不足」→ 去 platform.deepseek.com 充值
  · 提示「Key 无效」→ 在设置里重新粘贴完整的 Key,点「检测」确认
  · 换浏览器/换设备打开,需要重新走一遍首次向导
